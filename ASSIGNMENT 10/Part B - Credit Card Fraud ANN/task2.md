# Assignment 10B: Credit Card Fraud Detection Using ANN

## Objective

Credit Card Fraud Dataset par ANN develop karna hai jo transactions ko
fraudulent ya legitimate classify kare.

**Dataset:** Credit Card Fraud Dataset
**Dataset Link:** https://www.kaggle.com/datasets/quant101/cc-fraud-dataset

## Requirements

### 1. Data Preprocessing
- Dataset load aur EDA karein
- Missing values aur duplicates check karein
- Features (X) aur target (y) separate karein
- Class distribution check karein (imbalanced dataset)
- Train-test split (stratified) karein
- Feature scaling apply karein

### 2. Imbalanced Data Handling
- Class weights, undersampling, ya SMOTE use karein
- Test data ko balance nahi karna

### 3. ANN Model
- TensorFlow/Keras se ANN classification model banayein
- Different architectures experiment karein

### 4. Activation Functions
- Kam az kam 3 activation functions try karein: ReLU, Tanh, Sigmoid

### 5. Optimizers
- Kam az kam 3 optimizers try karein: Adam, SGD, RMSprop

### 6. Evaluation
- Accuracy, Precision, Recall, F1-Score, Confusion Matrix calculate karein
- Recall ko specially analyze karein

### 7. Model Comparison
- Har model ka comparison table banayein
- Best model identify karein with reasoning

### 8. Prediction
- Best model se predictions karein
- Sample transactions ki actual vs predicted classes dikhayein

## Submission
1. Jupyter Notebook
2. Preprocessing code
3. Imbalanced data handling
4. ANN model code
5. Experiment results
6. Evaluation metrics
7. Model comparison table
8. Short conclusion
