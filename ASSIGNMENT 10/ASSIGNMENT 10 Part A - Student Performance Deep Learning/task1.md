# Assignment 10A: Student Performance Prediction Using Deep Learning

## Objective

Student Performance Dataset par Artificial Neural Network (ANN) develop karna hai
jo students ka final_grade predict kare.

**Dataset:** 300K Student Performance Prediction Dataset
**Dataset Link:** https://www.kaggle.com/datasets/rhythmghai/300k-student-performance-prediction-dataset

## Requirements

### 1. Data Preprocessing
- Dataset load aur basic EDA karein
- Missing values aur duplicates check karein
- Categorical data ko encode karein
- Features (X) aur target (y) separate karein
- Train-test split karein
- Feature scaling apply karein

### 2. ANN Model
- TensorFlow/Keras ka use karke ANN banayein
- Different architectures experiment karein (layers, neurons, epochs, batch sizes)

### 3. Activation Functions
- Kam az kam 3 activation functions try karein: ReLU, Tanh, Sigmoid

### 4. Optimizers
- Kam az kam 3 optimizers try karein: Adam, SGD, RMSprop

### 5. Model Comparison
- Har model ka comparison table banayein
- Best model identify karein with reasoning

### 6. Prediction
- Best model se test data par predictions karein
- Sample predictions dikhayein

## Submission
1. Jupyter Notebook
2. Preprocessing code
3. ANN model code
4. Experiment results
5. Model comparison table
6. Short conclusion
